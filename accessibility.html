Accessibility Statement

Last updated: November 2026

Otticode is committed to ensuring digital accessibility for people with disabilities. We continually work to improve the user experience for everyone and apply the relevant accessibility standards.

Conformance status

The Web Content Accessibility Guidelines (WCAG) define requirements for designers and developers to improve accessibility for people with disabilities. This website aims to conform to WCAG 2.2 Level AA.

What we have done

  • Skip-to-content navigation links on every page
  • Semantic HTML landmarks (<main>, <nav>, <footer>) with ARIA labels
  • Proper heading hierarchy (h1 → h2 → h3) with no skipped levels
  • Colour contrast ratios meeting or exceeding WCAG AA thresholds for all text, including text placed on the orange accent colour
  • Visible focus indicators on all interactive elements (links, buttons, form controls), with a variant that stays visible on dark and accent backgrounds
  • Form inputs with properly associated labels and autocomplete attributes
  • Decorative elements (icons, status stickers, the scrolling keyword strip) hidden from assistive technology
  • A text-based wordmark, so the brand does not depend on an image
  • Language attribute set on every page
  • Reduced-motion support for users who prefer minimized animations
  • Text resize and reflow without loss of content, tested down to a 390 px viewport

Known limitations

We are not aware of any outstanding barriers to WCAG 2.2 Level AA conformance on this site. If you find one, we would like to hear about it — see Feedback below.

Feedback

We welcome your feedback on the accessibility of this website. If you encounter any barriers or have suggestions for improvement, please reach out via our contact form or email us at hello@otticode.com.
